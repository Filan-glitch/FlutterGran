The engines for the modes beyond x01 - Around the Clock, Bulling,
Higher/Lower - and solo training, each pure Dart and laid out the same way: a
config, a leg state, and a reducer that folds the dart log into it, as
`foldAroundTheClock`, `foldBulling`, `foldHigherLower` and `foldFreePractice`
do.

The controllers, screens, sounds and lights that run each mode are under
**App**.
